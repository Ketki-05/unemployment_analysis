# Unemployment Analysis in India

#Project Overview
This project analyzes unemployment trends in India using Python and data visualization techniques. It explores changes in the estimated unemployment rate over time, compares unemployment rates across regions, and examines the impact of the COVID-19 lockdown on unemployment.

#Objectives
- Analyze unemployment rate trends over time.
- Explore and summarize unemployment data.
- Compare average unemployment rates across different regions.
- Study monthly unemployment patterns.
- Visualize the possible impact of the COVID-19 lockdown on unemployment rates.

#Technologies Used
Python— Programming language
Jupyter Notebook — Development environment
Pandas — Data manipulation and analysis
Matplotlib — Data visualization
Seaborn — Statistical data visualization

#Dataset
The project uses the dataset `Unemployment_Rate_upto_11_2020.csv`.

The notebook analyzes fields including:
- Date
- Region
- Estimated Unemployment Rate (%)

The dataset is used to examine unemployment trends over time and differences between regions.

#Expected Outcomes
- Understand changes in unemployment rates over time.
- Compare average unemployment rates across regions.
- Observe monthly unemployment patterns around the COVID-19 lockdown.
- Develop practical skills in data cleaning, exploratory data analysis, and visualization.

#Conclusion
This project demonstrates how Python-based data analysis and visualization can be used to explore unemployment trends in India. The visualizations help present temporal and regional patterns in the dataset and support further investigation of unemployment during the COVID-19 period.
