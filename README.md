#Unemployment Analysis in India
This project analyzes unemployment trends in India using Python. 
It uses Pandas for data analysis and Matplotlib and Seaborn for data visualization.
The project explores unemployment rates over time, compares unemployment across different regions, and examines changes during the COVID-19 lockdown period.

#Technologies Used: 
Python, Pandas, Matplotlib, Seaborn, and Jupyter Notebook.

#bjective: 
To understand unemployment patterns and identify trends through data analysis and visualization.
